# Архитектура

Broker Lab — статический React SPA с hash-маршрутами для GitHub Pages.

На первом этапе сценарии декларативно описывают шаги, состояние сообщения и события. Движок `src/engine/core/player.ts` отвечает за навигацию, смысловое переключение между брокерами, построение журнала и проверку сценариев. Он не зависит от React.

Предметный контент находится в `src/content`, UI — в `src/components` и `src/pages`. Состояние плеера и тема сохраняются локально. Серверной части нет.

Полный целевой состав модулей и следующих этапов описан в `PRODUCT_PLAN.md`.
