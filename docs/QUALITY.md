# Проверка качества

## Матрица проверок

Перед публикацией выполняются:

```bash
pnpm lint
pnpm typecheck
pnpm test
pnpm build
pnpm test:e2e
```

Unit-тесты проверяют структуру сценариев, источники, глоссарий, навигацию, журнал, смысловое переключение брокеров и предметные инварианты S01.

E2E-тесты запускаются в Chromium и Firefox. Покрыты нормальный путь, различия ack/commit, position и committed position Kafka, reload, поиск, глоссарий, клавиатурный фокус, мобильная навигация, видимость реплик, ширины 320–1440 px и axe для обеих тем и основных страниц.

Визуальная проверка выполняется отдельно по скриншотам: автоматические тесты не заменяют просмотр компоновки.

## Исправления после аудита вертикального среза

- Разделены Kafka consumer position и committed position: poll автоматически продвигает локальную позицию, commit меняет сохранённую.
- Kafka использует состояние processing вместо неправильной аналогии с RabbitMQ unacked.
- Реплики Kafka исключены из основного flow и отображаются только как ветка partition leader.
- Устранена общая прокрутка desktop-страницы; внутренние панели прокручиваются независимо.
- Мобильная топология заменена вертикальным путём, активное сообщение прокручивается в видимую область.
- Управление шагами доступно на всех мобильных вкладках.
- Диалог поиска возвращает клавиатурный фокус исходному элементу.
- Кнопка «Открыть на схеме» действительно переключает мобильную вкладку.
- ID сообщения и внешнего эффекта берутся из сценария, а не из разметки компонентов.
- Контраст, доступные имена, landmarks и размеры мобильного текста проверены автоматически и визуально.

## Границы проверки

Симуляция не проверяет реальную производительность и не заменяет интеграционные тесты с брокерами. Для каждого нового сценария нужно отдельно ревьюить предметные утверждения по указанным официальным источникам.
